VARIÁVEIS E CONSTANTES

É muito imortante em uma linguagem de programação poder armazenar dados de forrma temporária, essa é a finção daaas variáveis, semore que precisar armazenar uma informação, vamos usar as variaveis, podemos inserir, remover ou alternar informação em variáveis.

VARIÁVEIS

Declarar variáveis em javascript é bem simples, diferente de linguagens tradicionais como C++, em java não informamos o tipo de dados e por isso nãó precisamos de operações como typecast, basta usar a palavras reservada "var" e o nome da variáveis, veja a seguir o código básico se declarar uma variável.

CONST

Constantes tem uma diferença importante em relação as variaveis, elas não podem ser modificadas, uma vez declarada a atribuida uma constante, seu valor mão pode mais ser modificado. A sintaxe de declaração é mesma da variavel com exceção da palavra "var" que será´substituida pela palavra "const".




CAIXA DE MENSAGENS

Uma otima forma de comunicação com o usuario ou uma forma alternativa de colher dados para nosso programa são as caixas de mensagens, em javascript existem tres tipos diferentes, são eles alert, prompt e confirm.

ALERT

A caixa de mensagem mais simples é a caixa "alert", mostra uma mensagem simples com um botão OK, o comando é bem simples, basta inserir o conteúdo que será mostrado na caixa de texto dentro dos parênteses.

PROMPT

A caixa de mensagem prompt se diferencia por possibilitar a entrada de texto, permitindo que esse texto seja coletado e passado a uma variável, desta maneira é a forma de coletar dados externos.

CONFIRM

A caixa de mensagem confirme se particulariza por apresentar uma mensagem simples, dois botões OK e Cancelar. Mas sua funcionalidade mais importante é o retorno de qual dos botões foi pressionado, caso seja clicado em OK a caixa retorna o valor "true" e caso seja clicado Cancelar a caixa retorna o valor "false", simples assim.

Criamos uma variavel chamada "entrada" sem valor definido. Usamos a variáveis opc para receber do método confirm, lembre-se, se o botão OK for clicado o método retorna "true" (verdadeiro) e se Cancelar for clicado o retorno "false" (falso).

ESTRUTURA DE DECISÃO IF

Em qualquer lugar de programação é extremamente importante podermos analizar um certo conteúdo ou resultado para direcionar a execução do nosso programa e determinar uma rotina ou outra a ser executada.

IF

A principal estrutura de decisão em programação é definida pelo comando IF, que traduzindo do inglês é SE.

Nessa sintaxe o IF verifica dp "teste lógico" e se for verdadeiro "true" ele executa os comandos entre suas chaves {}, caso contrário, se for falso, os comandos não serão executados e pulará para a proxima instrução após o IF.

O que é o "teste lógico"?

Basicamente o comando IF necessita de uma expressão que retorne "verdadeiro (true)" ou "falso (false)" e estes são os valores de retorno de qualquer teste lógico, basicamente é uma comparação que usa os operadores lógicos <, >, >=, <=, !=, ==.
